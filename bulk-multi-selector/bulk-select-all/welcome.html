Bulk Select All

Select checkboxes, images and files in bulk with one click

Quick start

  1. Open the page with the list you want to download (each row has a checkbox).
  2. On the floating panel (bottom-right) click Select + scroll to bottom — or open the toolbar popup.
  3. Leave the tab open: the extension scrolls the list, waits for lazily loaded rows and checks everything.
  4. When it finishes, use the page's own Download button as usual.

Tips

  • Shortcut: Alt + Shift + A (change it at edge://extensions/shortcuts).
  • Enable Auto-select on page load to check everything automatically the next time you open that site.
  • Nothing happens? The page was opened before the extension was installed — open the popup and click Reload page (or press F5).
  • Virtualized lists (only a few rows rendered): keep auto-scroll on, the extension scrolls step by step and checks every row.
  • Slow page? Raise Wait per scroll step to 500–800 ms in the popup.

Settings

Open the extension popup → Advanced settings to tune click delay, scroll speed, idle rounds, “Select all” header preference and scroll restore.
